¿Cómo funciona la conversión de archivos a QR?

Un código QR es esencialmente una matriz visual que codifica texto. Dependiendo del tamaño del archivo que subas, nuestra aplicación aplica automáticamente dos estrategias:

Modo 1: Incrustación Directa (Archivos < 2 KB)

Si subes un archivo de texto plano, JSON, CSV o un micro-archivo menor a 2,000 bytes, codificamos su contenido real (o Data URL) directamente dentro de los píxeles del QR. No requiere internet ni servidores para leerse.

Modo 2: Enlace de Descarga / Nube (Archivos > 2 KB)

Un PDF, fotografía o audio pesa cientos de kilobytes o megabytes, lo cual excede la capacidad física de cualquier código QR estándar (máximo 2,953 bytes). Para estos casos:

  • Puedes pegar el enlace público de Google Drive, Dropbox o OneDrive.
  • O usar nuestro Simulador de Alojamiento que genera una tarjeta de descarga interactiva con los datos del archivo.

Conectar a un Backend Real en Producción

Actualmente esta aplicación funciona 100% en el navegador (Frontend) sin requerir base de datos. Si deseas que cualquier usuario suba archivos pesados y se hospeden automáticamente en tu propio servidor:

Arquitectura Recomendada:

  1. Almacenamiento (Storage): Usa AWS S3, Cloudflare R2, Firebase Storage o Supabase Storage para guardar el archivo binario.
  2. API Backend (Node.js + Express + Multer): Crea un endpoint POST /api/upload que reciba el FormData, lo suba al bucket y devuelva una URL pública corta (ej. https://tudominio.com/f/abc123).
  3. Conexión con este Frontend: Reemplaza la función simulada processLargeFile() por una petición fetch('/api/upload', { method: 'POST', body: formData }) y pasa la URL devuelta a generateQR(data.url).
Ejemplo rápido en Node.js / Express: 
app.post('/api/upload', upload.single('file'), async (req, res) => {
  const publicUrl = await uploadToCloudStorage(req.file);
  res.json({ success: true, downloadUrl: publicUrl });
});
